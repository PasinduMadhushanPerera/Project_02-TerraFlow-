## 🔐 Security Implementation

### Access Control
- **Role-Based Routing**: Suppliers can only access supplier pages
- **JWT Authentication**: Secure token-based authentication system
- **Data Isolation**: Suppliers only see their own material requests and deliveries
- **Protected APIs**: All supplier endpoints require authentication and role verification

### Authentication Flow
```
1. Login → JWT Token Generation
2. Token Validation on Every Request
3. Role Verification (Supplier/Admin)
4. Data Access Control by Supplier ID
```
